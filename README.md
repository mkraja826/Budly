# Budly

**Learn. Play. Grow. 🌱**

Budly is an international children's learning platform for ages 3–10, designed around safe, adaptive, developmentally appropriate learning.

## Status

Production foundation is under active development. The initial architecture deliberately keeps the learning engine deterministic, explainable, offline-capable, and independent of external AI providers.

## Product principles

- Parent/guardian-controlled accounts; child profiles are subordinate and privacy-minimized.
- Universal skill taxonomy decoupled from any single curriculum.
- Immutable learning evidence with derived mastery state.
- Internationalization and RTL support are foundation requirements.
- AI is an enhancement layer, never the core learning engine.
- Healthy rewards optimize for learning outcomes, not screen time.
- Offline learning must preserve progress and synchronize safely.

## Development

Implementation work should happen on feature branches and land through reviewed pull requests. See `docs/architecture/FOUNDATION.md` for the initial architecture boundary and roadmap.
